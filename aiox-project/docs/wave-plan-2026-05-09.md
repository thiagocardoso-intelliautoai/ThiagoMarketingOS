## Como Rodar

```bash
# Sessão dedicada (zero permission prompts)
claude --dangerously-skip-permissions

# Pre-flight (só perguntas, não executa)
> /run-wave 0 --preflight-only

# Execução
> /run-wave 0
> /run-wave 1
> /run-wave 2
# ...

# Retomar de onde parou
> /run-wave --resume

# Story específica (resolve deps)
> /run-wave LCOMM-013

# Múltiplas waves seguidas
> /run-wave 0,1,2
```

**Após cada wave, antes de `/run-wave` da próxima:**
1. Revise os commits locais: `git log --oneline -20`
2. Se quiser pushar: `/devops` → `*push`
3. Se algo deu errado: `git reset --hard {hash-antes-da-wave}` e re-rode com fix
